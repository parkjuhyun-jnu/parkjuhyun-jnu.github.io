데이터베이스와 SQL 실습 자료

3강 ‘데이터베이스와 SQL’의 실습 자료입니다. 두 주에 나눠 진행합니다. 작은 도서관 DB(도서·저자·소장 자료·이용자·대출)의 구조를 그림으로 보고, 브라우저에서 바로 SQL을 써 봅니다. 설치할 프로그램도, 가입도 없습니다.

SQL 실습실 열기 DB 구조 보기 (ERD) DB 파일 받기 (library.sql)

강의 슬라이드(PDF): 1주차 · 3강 ① · 2주차 · 3강 ②

실습 전에 노트북(또는 태블릿)과 인터넷이 필요합니다. 크롬·엣지·사파리 최신판이면 됩니다. 실습실에서 바꾼 자료와 맞힌 문제 기록은 내 브라우저에만 남고, 다른 사람에게 보이지 않습니다. 이용자·대출 자료는 모두 가상입니다.

1주차 · 3강 ① 구조: 관계형 DB 읽기와 한 테이블 질의

테이블·행·열, 기본 키와 외래 키, ERD, 정규화를 배우고 SELECT로 한 테이블에 묻습니다.

  • 실습 1DB 구조 읽기: ERD에서 PK·FK를 찾고, 『소년이 온다』가 book·item·loan에 어떻게 나뉘어 있는지 따라가기 DB 구조 보기15분
  • 실습 2SELECT 기초 8문제 (1-1 ~ 1-8): 열 고르기, WHERE, ORDER BY, LIKE, NULL, COUNT, DISTINCT 실습실 1-1부터35분
  • 생각 1왜 표를 나눌까: 출판사 이름을 book에 바로 적으면 생기는 일 (채점 없음, 짝 토론)5분

2주차 · 3강 ② 잇기: JOIN·집계·데이터 바꾸기

여러 테이블을 잇고, 묶어 세고, 넣고·고치고·지웁니다. 마지막에 DB 설계를 LRM·메타데이터 관점으로 다시 봅니다.

  • 실습 3JOIN 5문제 (2-1 ~ 2-5): 출판사·분류·저자·옮긴이 잇기, 한 번도 안 빌린 책 실습실 2-1부터25분
  • 실습 4집계·하위 질의 7문제 (2-6 ~ 2-12): GROUP BY, HAVING, 연체, 평균 실습실 2-6부터30분
  • 실습 5데이터 바꾸기 3문제 (2-13 ~ 2-15): INSERT · UPDATE · DELETE, 그리고 도전 과제(서평 테이블 만들기) 실습실 2-13부터15분
  • 생각 2저작은 어디에 있나: ‘어린 왕자’ 세 종을 LRM으로 읽고 work 테이블 설계해 보기 (채점 없음)10분

실습실은 sql.js(SQLite를 브라우저에서 돌리는 공개 라이브러리)를 씁니다. 실습실에서 만든 결과를 다른 프로그램(DB Browser for SQLite 등)에서 이어 하려면 library.sql을 받아 열면 됩니다.
