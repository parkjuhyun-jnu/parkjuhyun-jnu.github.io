실습 3. API로 직접 가져오기 (15분)

API는 주소로 자료를 달라고 요청하는 창구입니다. 주소의 일부(바꿀 자리)만 바꾸면 다른 자료가 옵니다. 이 실습에서는 주소를 바꿔 자료를 받고, 받은 자료의 생김새를 읽어 표제·ISBN·저자가 어디에 들어 있는지 찾습니다.

  1. 아래에서 서비스를 고릅니다. Open Library부터 하세요.
  2. 주황색 칸의 값을 바꾸면 주소도 함께 바뀝니다. 어느 부분이 바뀌는지 보세요.
  3. 응답 보기로 서버가 보낸 원래 자료를 확인합니다.
  4. 나무로 보기에서 항목을 누르면 그 값까지 가는 길(경로)이 나옵니다. 표제·ISBN·저자의 경로를 찾아 적습니다.
  5. 나무를 보고 종이에 간단히 따라 그립니다(최상위 → 객체·요소 → 배열 → 값).

실습 4. 링크드 데이터 따라가기 (7분)

링크를 따라 국립중앙도서관에서 Wikidata까지 기관을 넘어 『어린 왕자』를 찾아갑니다. 각 단계의 페이지는 새 탭으로 열립니다. 끝낸 단계는 왼쪽 칸에 표시하세요.

  • 1. 책에서 출발합니다. 국립중앙도서관 LOD 『어린 왕자』(문학동네, 2007) 열기
    책 한 권의 정보가 ‘속성 - 값’ 표로 나옵니다.
  • 2. 저자로 건너갑니다. 표에서 dcterms:creator 줄을 찾아 nlk:KAC199623935를 누릅니다.
    막히면: 저자 페이지 바로 열기
  • 3. 다른 기관으로 넘어갑니다. 저자 페이지에서 owl:sameAs 줄을 찾습니다. ‘같은 대상’이라는 뜻입니다. 여러 주소 가운데 www.wikidata.org로 시작하는 것을 누릅니다.
  • 4. 다시 작품으로 돌아옵니다. Wikidata의 저자 항목에서 notable work(대표작) 칸을 찾아 『어린 왕자』를 누릅니다. 화면 언어에 따라 칸 이름이 다를 수 있습니다.
    주소 끝이 Q25338이면 도착입니다. 막히면: Q25338 바로 열기

한 바퀴 돌았습니다. 책 → 저자 → Wikidata → 작품까지, 서로 다른 기관의 자료가 주소(URI)로 이어져 있습니다.
