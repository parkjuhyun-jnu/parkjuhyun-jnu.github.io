실습 3~5 링크 모음 (메타데이터론 2강)

링크를 누르면 실제 서버가 보낸 응답이 열립니다. 아래 링크는 모두 2026-10-29~30에 응답을 확인했습니다.
주황색은 바꿀 자리입니다. 주소창에서 그 부분만 고치고 Enter를 누르세요.

실습 3. API로 직접 바꿔서 가져오기

먼저 예시 링크를 열어 보고, 다음에는 바꿀 자리를 고쳐서 다시 가져옵니다.

  1. LC SRU (XML) — 예시: 『The Little Prince』 MARCXML
    틀: http://lx2.loc.gov:210/LCDB?version=1.1&operation=searchRetrieve&query=bath.isbn=ISBN&maximumRecords=1&recordSchema=marcxml|mods|dc
    recordSchema만 mods, dc로 바꿔 같은 책을 세 형식으로 받아 보세요. 영어책 ISBN을 넣으면 찾을 가능성이 높습니다.
  2. Open Library (JSON) — 예시: openlibrary.org/isbn/9780156012195.json
    틀: https://openlibrary.org/isbn/ISBN.json
    검색 틀: https://openlibrary.org/search.json?q=검색어&limit=5 — 예: q=the+little+prince
  3. Crossref (JSON, 논문) — 예시: api.crossref.org/works/10.1038/sdata.2016.18
    틀: https://api.crossref.org/works/DOI
    한국 학술지 DOI는 대부분 KISTI에 등록되어 Crossref에서는 '찾을 수 없음'이 나올 수 있습니다.
  4. 국립중앙도서관 LOD (JSON·Turtle, 키 없음) — 예시: KMO200722491 JSON · Turtle · 사람용 페이지
    틀: https://lod.nl.go.kr/data/리소스번호?output=json|ttl|rdfxml
    리소스 번호 예: KMO200722491(어린 왕자, 문학동네), KJU200003488(어린 왕자, 비룡소), WMO202006856(The little prince, Harcourt), KAC199623935(생텍쥐페리)
  5. OAI-PMH (XML) — 예시: verb=Identify · GetRecord
    틀: https://oaipmh.arxiv.org/oai?verb=GetRecord&identifier=oai:arXiv.org:논문번호&metadataPrefix=oai_dc

그리기: 받은 응답 하나를 골라 종이에 나무 모양으로 그리세요(최상위 → 객체/요소 → 배열 → 값). 제목·ISBN·저자까지 가는 길을 화살표로 표시합니다.

실습 4. 링크드 데이터 따라가기
