1주차 · 2강 ① 그릇: XML과 JSON 읽고 쓰기

단추를 누르면 웹 화면에서 바로 합니다. 인터넷이 없을 때는 맨 위의 zip을 받아 메모장과 브라우저로 할 수 있습니다.

  • 실습 1
    book.xml 쓰고, 일부러 틀린 파일 고치기

    XML은 문법이 한 군데만 틀려도 컴퓨터가 읽지 못하고 오류를 냅니다. 내 손으로 XML을 써 보고, 오류 메시지를 읽어 고치는 연습입니다. 단추를 누르면 고치는 화면이 열립니다. 메모장은 없어도 됩니다.

    1. 쓰기 ‘빈칸’을 눌러 ____ 자리를 채우고 검사를 누릅니다.
    2. 고치기 오류1부터 차례로 누릅니다. 틀린 파일이 열리면 몇째 줄이 문제인지 보고 고칩니다. ‘통과’가 나오면 다음으로 넘어갑니다.
    빈칸 오류1 오류2 오류3 오류4 오류5

  • 실습 2
    book.json 쓰고, 일부러 틀린 파일 고치기

    실습 1과 같은 방식을 JSON으로 합니다. JSON은 숫자·참거짓·빈 값에 따옴표를 붙이지 않고, 글자는 큰따옴표로만 감쌉니다.

    1. 쓰기 ‘빈칸’을 눌러 값의 유형에 맞게 채우고 검사를 누릅니다.
    2. 고치기 오류6부터 차례로 고칩니다.
    빈칸 오류6 오류7 오류8 오류9
    10분

2주차 · 2강 ② 가져오고 잇기: API에서 LRM까지

모든 실습이 인터넷을 씁니다. 노트북을 가져오세요.

  • 실습 3
    API 주소를 바꿔 자료를 직접 가져오고, 응답 구조 읽기 (Open Library · LC SRU · Crossref · 국립중앙도서관 LOD)

    API는 주소로 자료를 달라고 요청하는 창구입니다. 주소의 일부를 바꿔 다른 자료를 받아 보고, 받은 자료에서 표제·ISBN·저자가 어디에 들어 있는지 찾습니다. 단추를 누르면 따라 하는 화면이 열립니다.

    링크드 데이터 따라가기: 국립중앙도서관 LOD → Wikidata → 『어린 왕자』

    링크를 눌러 가며 책 → 저자 → Wikidata → 작품까지 기관을 넘어 한 바퀴 돕니다. 네 단계를 차례로 안내합니다.

    SPARQL로 국립중앙도서관 데이터에 묻기 (질의 세 개)

    SPARQL은 링크드 데이터에 질문하는 언어입니다. 실습 4에서 손으로 눌러 따라간 것을 이번에는 질문 하나로 받아 봅니다. 화면에서 바로 실행하고, 원하면 국립중앙도서관 편집기에서도 돌려 봅니다.

    LRM은 ‘책’이라는 말을 네 층으로 나눠 보는 국제 모형입니다. 비룡소판 레코드의 실제 값을 하나씩 칸에 넣고, 문학동네판과 견주어 어디가 같고 다른지 봅니다.
